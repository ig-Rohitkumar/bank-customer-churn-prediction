# Bank Customer Churn Prediction

A machine learning-based web application that predicts customer churn risk for banks using Random Forest classification and Streamlit deployment.

## Live Demo

https://bank-customer-churn-prediction-g3kj6aazkghccbntfawyuk.streamlit.app/

## Features

* Customer churn prediction
* Risk categorization
* Feature engineering
* Interactive Streamlit dashboard
* Probability-based predictions

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit

## ML Model

* Random Forest Classifier
* ROC-AUC Score: 0.86
* Accuracy: 87%

## Dataset

European Bank Customer Dataset
